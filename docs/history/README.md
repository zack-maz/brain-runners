# How Brain Runners was built

The build record, kept as it was written: paths and names inside these files are as they were then (the project
was brain-bakeoff, its front Brain Battle and then Brain Run, and `calibration/` sat at the top of the repository).
What each step decided is in `docs/DECISIONS.md`, which the code and the write-up cite by number.

| | |
|---|---|
| `superpowers/specs/` | The design of each phase, approved before it was built. |
| `superpowers/plans/` | The implementation plan of each phase, task by task. |
| `mockups/` | The approved mock-ups of the Brain Runners screens. |
| `NEXT.md` | The running state of the project while it was built, rewritten as it changed. |
| `UPDATES.md` | The ten updates made before the study. |
| `FRONTEND.md` | The brief and the answers behind the Brain Runners screens (called Brain Battle then). |
| `REFERENCE.md` | The README from while it was built: every command and screen in one long page. |
