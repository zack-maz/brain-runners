# What is in docs/

Brain Runners was built in the open, step by step, and this folder keeps the whole record: what was found, what was
decided, and how each piece was designed. Start with the first section; the rest is there for anyone who wants to
know why something is the way it is.

## The study and how to use it

| | |
|---|---|
| `SETUP.md` | Installing it and running it with your own keys, and how spending is kept in your hands. |
| `WRITEUP.html` | The study's write-up: which mind runs furthest for its cost and speed (also the Writeup screen). |
| `EXPLAINER.html` | The whole project in plain language, then the technical detail. Open it in a browser. |
| `WALKTHROUGH.md` | The manual: every command, every part of the page, and what each costs. |
| `REFERENCE.md` | The README from while it was built: every command and screen in one long page. |
| `COSTS.md` | Every paid run: what it cost and what it showed. |

## How it was decided

| | |
|---|---|
| `DECISIONS.md` | Every decision, numbered and only ever added to. The write-up and the code cite them by number. |
| `NEXT.md` | The running state of the project while it was built. |
| `UPDATES.md` | The ten updates made before the study. |
| `FRONTEND.md` | The brief and the answers behind the Brain Runners screens (called Brain Battle then). |

## How it was designed and built

| | |
|---|---|
| `superpowers/specs/` | The design of each phase, approved before it was built. |
| `superpowers/plans/` | The implementation plan of each phase, task by task. Paths in them are as they were then (`calibration/` has since moved under `docs/`). |
| `mockups/` | The approved mock-ups of the Brain Runners screens. |
| `STEP_RECORD.md`, `REPLAY_DATA.md` | The formats: one decision's record, and the replay the page draws. |

## The fly

| | |
|---|---|
| `RESEARCH.md` | The fly-brain resources behind the simulation. |
| `research/` | Deeper research on the fly's circuits and the FlyWire tools, kept as written: paths and scripts in it are as they were then (`calibration/` has since moved under `docs/`). |
| `calibration/` | How the flies' thresholds and inputs were fixed on practice tracks, then frozen: `REPORT.md` (fly) and `FLY2_REPORT.md` (fly2). |
| `spikes/` | The five probes' reports (and the first one's brief). Their throwaway code stayed on local branches, so where `DECISIONS.md` or `NEXT.md` says a report is "on branch `spike/…`", read `docs/spikes/`. |

`media/` holds the images the README shows.
